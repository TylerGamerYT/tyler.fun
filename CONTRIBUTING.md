# Contributing to tyler.fun

This is a guide on how to contribute to tyler.fun.

## Getting Started

1. **Fork the repository and clone it locally.** Create a personal copy of the project and download it to your development environment.
2. **Create a new branch for your feature or bug fix.** Ensure your branch name is descriptive of the changes you are making.
3. **Make your changes and ensure they work as expected.** Verify that your implementation is functional and does not introduce new issues.
4. **Submit a Pull Request (PR) with a clear description of your changes.** Detail what was modified and the purpose of the update for the maintainers to review.

## Contributor Badge

Contributors to the project are eligible for a special **Contributor Badge**. This badge is displayed on your tyler.fun profile for any user with a registered account as recognition for your contribution.

To claim your badge, you need to add your tyler.fun user to your contribution. 

The badge is completely optional.

## Code Guidelines

* **Keep code clean and readable.** Ensure that your logic is easy for other developers to follow.
* **Follow the existing coding style of the project.** Consistency across the codebase is a priority.
* **Test your changes before submitting.** Manual or automated testing should be performed prior to opening a PR.
* **Implementation Standards.** Generally follow how other scripts do things and how they import other scripts to implement functionality to maintain architectural integrity.
