✦ The Beginning

  • tyler.fun officially existed as a live website.
  • The project had its first public version: v0.1.
  • The foundation was in place for everything that would be built in the releases that followed.

↗ Why this update?

Every project has to start somewhere.

v0.1 was that starting point for tyler.fun. It wasn't about having every feature or a huge collection of games yet - it was about getting the site out there and making the project real.

⌁ What came next

The first release was only the beginning. The site would soon get a redesign, its first batch of games, a growing changelog and eventually a much larger platform.
