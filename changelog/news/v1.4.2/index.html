Moved to Cloudflare Pages
& Infrastructure Upgrade

A major hosting update moving tyler.fun from Vercel to Cloudflare Pages, delivering improved global edge performance and faster deployment pipelines.

October 2026

✦ New

  • Migrated full platform deployment from Vercel to Cloudflare Pages.
  • Updated build configurations and automated edge deployment pipelines.
  • Optimized static asset routing across Cloudflare's global edge network.

↗ Infrastructure

  • Cloudflare Pages is now the primary hosting platform for tyler.fun.
  • Improved cold-start build times and reduced latency for international users.
  • Upgraded DNS routing and SSL configurations for unified edge performance.

◎ Why this update?

A long-term infrastructure step forward.

8 versions after moving to Vercel back in v0.9, tyler.fun has officially migrated to Cloudflare Pages. This change provides lower latency, faster deployment pipelines, and a stronger foundation as the site and its game library continue to scale.
